사용하는 정보 / Information used

Google 연결 시 이름·이메일·Drive 사용자 식별자로 계정과 파일 소유를 확인합니다. 할 일·일정·목표·일기·가족 보상·설정을 앱 전용 Google Sheets에 저장합니다. 선택한 사진·영상·음성은 Drive에, 선택한 장소와 좌표·직접 입력 또는 시스템으로 선택한 연락처 내용은 해당 기록에 포함될 수 있습니다. Calendar 연결은 선택이며 연결한 일정과 사용자가 선택한 다른 캘린더의 정보를 읽습니다.

Google connection uses your name, email and Drive user identifier to associate your account and files. App records save to app-specific Sheets; chosen photo, video and voice attachments save to Drive. A selected place and coordinates or contact content may be included in records. Optional Calendar integration reads connected events and other calendars selected by the user.

저장과 공유 / Storage and sharing

현재 별도의 하루모아 회원 데이터베이스 서버를 사용하지 않습니다. Google 서비스에서 기록을 처리하며 Google의 정책과 계정 설정도 적용됩니다. 비공개 원본과 가족용 자료는 별도 파일입니다. 가족 공유는 지정 계정에 필요한 읽기 권한을 부여하고 일기는 본인이 공유한 것만 표시합니다. 가족 공유 해제는 이미 복사된 자료를 회수하지 못합니다.

The current app has no separate Harumoa membership database server. Google processes connected records under its policies and account settings. Private originals and family projections are separate. Named-family accounts receive the necessary reader access; only explicitly shared journals appear to family. Revocation cannot recall copies already made.

Google 접근 범위 / Google access scopes

기본 저장은 앱이 만든 파일이나 사용자가 명시적으로 선택한 파일을 위한 drive.file 권한을 요청합니다. 현재 웹 가족 가져오기에는 전체 Sheets 권한을 요청하는 대체 경로가 있습니다. 이 경로의 실제 두 계정 접근은 검증되지 않았고, 운영 출시 전 파일별 Picker 방식으로 줄여야 합니다. Calendar의 앱 생성 캘린더·목록·읽기 권한은 별도로 요청하며 다른 기존 캘린더에 쓰는 기능은 제공하지 않습니다.

Core storage requests drive.file for app-created or explicitly selected files. The current browser family-import fallback requests broader Sheets access; two-account access is unverified and the fallback needs replacement by per-file Picker access before production. Optional Calendar requests app-created calendar, list and read-only event scopes; it does not write to other existing calendars.

기기 권한과 캐시 / Device permissions and caches

마이크와 위치는 해당 기능을 선택할 때 요청합니다. 미디어는 시스템 선택기를 사용합니다. 알림·정확한 알람·선택형 방해금지와 수면 안내에는 기기 권한 또는 특수 접근을 사용합니다. 수면 시간 최근 앱 사용 확인은 기기 안에서 처리하며, 그 목록을 Google에 보내는 경로는 현재 소스에서 발견하지 못했습니다. 기록·대기 중 수정·첨부 캐시는 기기에 남을 수 있습니다. Google 접근 토큰은 실행 중 메모리에 두고 Google 요청에는 HTTPS를 사용합니다. 종단간 암호화를 약속하지 않습니다.

Microphone and location are requested for chosen features. System media selection and notification/alarm/special-access settings support their respective features. Recent bedtime usage checks run locally; the current source shows no route uploading that list to Google. Devices can keep record, pending-edit and attachment caches. Google tokens stay in running memory and requests use HTTPS; this is not an end-to-end encryption promise.

다른 서비스 / Other services

현재 소스에는 광고·행동 분석 SDK를 추가하지 않았습니다. Google 로그인 라이브러리와 서비스의 처리에는 Google 정책이 적용됩니다. 지도 타일·외부 길찾기·웹 링크를 열면 해당 제공자로 요청이 전송될 수 있습니다. 최종 SDK·스토어 개인정보 항목 검토는 출시 전에 완료해야 합니다.

No advertising or behavioral analytics SDK was added in the current source. Google libraries and services are subject to Google's policies. Map tiles, directions and opened external links may send requests to their providers. Final SDK and store disclosure reviews remain before launch.

삭제와 철회 / Deletion and revocation

앱의 Google 연결 → 내 데이터 관리에서 DELETE를 입력하면 본인 소유의 하루모아 생성 Drive 파일을 휴지통으로 옮기고 로그아웃합니다. 영구 삭제와 Google 계정 삭제가 아닙니다. Calendar의 전체 제거, 다른 기기 캐시·사본의 일괄 삭제는 검증되지 않았습니다. Google에서 앱 접근 권한을 철회할 수 있으며 파일 삭제와는 별개입니다. 설치 없이 확인 가능한 삭제·문의 절차를 읽어 주세요.

Typing DELETE in Google connection → Manage my data moves your owned app-created Drive files to Trash and signs out. It is not permanent deletion or Google-account deletion. Complete Calendar and other-device cache/copy removal is unverified. Google access revocation is separate from file deletion. See the public deletion and contact instructions.

어린이와 변경 / Children and changes

13세 미만을 포함한 출시를 계획하고 있습니다. 현재 시험 버전에 법적 보호자 동의, 검증된 연령 확인·공유 통제가 운영 중이라고 주장하지 않습니다. 어린이 포함 운영 출시 전 이 절차와 감독 Google 계정의 API·SDK 사용 자격을 확인해야 합니다. 처리 방식이 바뀌면 이 안내와 스토어 표시를 업데이트합니다. 보호자 문의는 위 이메일로 보낼 수 있으며 비밀번호·접근 토큰·자녀의 실제 사진이나 일기를 보내지 마세요.

The planned audience includes children under 13. The test build does not establish an operating legal parental-consent, verified-age or sharing-control process. Those protections and supervised-account API/SDK eligibility must be confirmed before child-inclusive production. This information and store disclosures will change when processing changes. Parents may contact the email above without sending passwords, tokens, child photos or journal content.

Google API data use must comply with the Google API Services User Data Policy, including Limited Use requirements. Confirm that final operations comply before launch.
